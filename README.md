# 2026 Fantasy Basketball Draft Board

Ranks players by projected stats and compares them to their average draft position (ADP) on ESPN to find draft steals and busts (projected games played is taken into consideration).

## Scoring System

- PTS, REB, AST, STL, BLK, 3PM = 1 point
- TO = -1 point

Does not take player efficiency (FGM, FGA, FTM, FTA) into consideration.
